# TexasX artwork

The supplied Texas State Roleplay artwork is stored here. Public panels use Components V2 containers.

| Filename | Purpose | Recommended format |
| --- | --- | --- |
| `role-request-header.png` | Role-request banner | PNG |
| `departments-header.png` | Departments banner | PNG |
| `session-header.png` | Session banner above session announcements | PNG |
| `applications-header.png` | Applications banner | PNG |
| `assistance-header.png` | Assistance banner above the ticket panel | PNG |
| `marketplace-header.png` | Marketplace banner | PNG |
| `footer-banner.png` | Shared TXRP banner at the bottom of public panels | PNG |
| `texasx-logo.png` | TexasX logo | PNG |

If a panel asset is missing, the bot keeps the text-and-separator layout and omits that image.
