# TexasX artwork

The supplied Texas State Roleplay artwork is stored here. Public panels use Components V2 containers.

| Filename | Purpose | Recommended format |
| --- | --- | --- |
| `role-request-header.png` | `/self-roles` role selection panel | PNG |
| `departments-header.png` | TexasX dashboard, staff punishments, and staff role assignment/reinstatement responses | PNG |
| `session-header.png` | Session start/end announcements | PNG |
| `applications-header.png` | Hiring announcement and application decision | PNG |
| `assistance-header.png` | `/ticket-panel` assistance panel | PNG |
| `marketplace-header.png` | `/shop` panel | PNG |
| `footer-banner.png` | Shared TXRP banner at the bottom of public panels | PNG |
| `texasx-logo.png` | TexasX logo asset (not used as a panel banner) | PNG |

If a panel asset is missing, the bot keeps the text-and-separator layout and omits that image.
